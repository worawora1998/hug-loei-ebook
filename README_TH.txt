HUG LOEI E-BOOK WEBSITE — V2

เวอร์ชันนี้ปรับปรุง:
- หน้าแรกบนคอมเป็นหน้าปกเดี่ยวกลางจอ แล้วเปิดออกเป็นหนังสือ 2 หน้า
- Desktop: หน้า 2–3, 4–5, 6–7 ... แสดงเป็น spread ตามลำดับหนังสือจริง
- Mobile: แสดงทีละ 1 หน้า
- Page Turn 3D ใหม่: ด้านหลังของกระดาษใช้ภาพหน้าถัดไปจริง พร้อมแสง เงา และ paper curl
- ที่คั่นเพิ่ม หน้าแรก / คำนำ / สารบัญ + 14 อำเภอ
- ที่คั่นบนมือถือเป็นริมสีด้านขวา แตะแล้วเลื่อนออกก่อนข้ามหน้า
- หน้าสารบัญจริงหน้า 3 ยังคงคลิกชื่ออำเภอเพื่อข้ามหน้าได้
- Zoom / Fit to screen / Swipe / Keyboard / Fullscreen
- Share deep-link ของหน้าปัจจุบัน
- Reading progress bar
- ใช้ Google Font: Kanit
- ธีมหน้าเว็บปรับให้สดใสและใกล้เคียงบรรยากาศ HUG LOEI
- Service Worker cache หน้าที่เคยเปิด เพื่อการกลับมาอ่านซ้ำที่เร็วขึ้น (ทำงานเมื่อ deploy ผ่าน HTTPS)

การใช้งาน:
1) อัปโหลดทั้งโฟลเดอร์ขึ้น Netlify / Vercel / Cloudflare Pages / Hosting
2) เปิด index.html ผ่านเว็บเซิร์ฟเวอร์
3) ถ้าเปิดไฟล์ index.html ตรงๆ บนคอม ฟังก์ชันหลักใช้งานได้ แต่ Service Worker จะไม่ทำงานใน file://

หมายเหตุ:
- ภาพหน้า E-Book ในโฟลเดอร์ pages/ ยังคงใช้ไฟล์เดิม ไม่ถูกลดคุณภาพใน V2
- Google Font ต้องมีอินเทอร์เน็ต หากโหลดไม่ได้จะใช้ฟอนต์สำรองของระบบ
