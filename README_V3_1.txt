HUG LOEI E-Book Website V3.1
============================

อัปเดตจาก V3 ตามข้อเสนอแนะล่าสุด:
- แก้ปัญหากลับไปหน้าแรกแล้วหน้าปกหาย โดยล้างสถานะ animation ของกระดาษทุกครั้งก่อน render
- แก้หน้าปิดท้ายเล่มมีแถบ/หน้าว่างโผล่ด้านขวา โดยซ่อนแผ่นขวาอย่างสมบูรณ์ในโหมดปกหน้าและปกหลัง
- เพิ่มปุ่ม “อัปเดต PDF” บน Toolbar ของหน้าอ่าน E-Book โดยตรง (Desktop และ Mobile)
- เพิ่มโลโก้หลัก HUG LOEI จาก PNG ที่ผู้ใช้แนบมา โดยเก็บไฟล์ต้นฉบับไว้ใน assets/logos/source/
- นำปุ่ม “ติดต่อ” แบบข้อความออก
- ย้ายชุดโลโก้หน่วยงานผู้จัดทำไปด้านขวาล่าง และขยายให้เห็นชัดขึ้น
- ชุดโลโก้หน่วยงานยังสามารถกดเพื่อเปิดช่องทางเว็บไซต์/Facebook ได้
- หน้า update.html เพิ่มโลโก้ HUG LOEI ให้รูปแบบสอดคล้องกับหน้าอ่าน
- Service Worker เปลี่ยน cache version เพื่อไม่ให้เครื่องที่เคยเปิด V3 ค้างไฟล์ CSS/JS รุ่นเก่า

หมายเหตุเกี่ยวกับโลโก้ HUG LOEI:
- source/hug-loei-main.png = PNG ต้นฉบับที่ผู้ใช้แนบ
- ui/ และ mini/ = การย่อขนาดจาก PNG ต้นฉบับเพื่อให้โหลดเร็วขึ้นเท่านั้น ไม่มีการวาด/Generate โลโก้ใหม่

เปิดใช้งาน:
- ดูแบบ static: เปิด index.html หรืออัปทั้งโฟลเดอร์ขึ้น Hosting
- ใช้ระบบอัปเดต PDF แบบเขียนไฟล์จริง: ใช้ RUN_UPDATE.bat หรือ python server.py
